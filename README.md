# Athira Prasad — Portfolio Website

A responsive, static portfolio template built with HTML, CSS, and a small amount of JavaScript. It is designed to be easy to customise and publish with GitHub Pages.

## Files
- `index.html` — page content
- `styles.css` — layout, colours, typography, and responsive styles
- `script.js` — mobile navigation toggle

## Customise before publishing
1. Update the email address and location in `index.html`.
2. Replace the GitHub and LinkedIn profile links with your real profile URLs.
3. Review all skill and project descriptions so they accurately reflect your experience.
4. Add public project repository/demo links only when you have permission to share them.
5. Do not publish passwords, access tokens, employer code, client data, or confidential screenshots.

## Preview locally
Open `index.html` in your browser.

## Publish using GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under build and deployment, choose **Deploy from a branch**.
5. Select your main branch and the root (`/`) folder, then save.
6. Wait for the Pages deployment to finish and open the URL GitHub provides.

GitHub's interface may change. Use the current GitHub Pages documentation if a setting is different.
